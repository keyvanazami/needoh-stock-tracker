## Manchester coding (802.3: bit0->10, bit1->01)
  0x00 -> AA AA   (popcount 4+4, DC balanced)
  0xFF -> 55 55   (popcount 4+4, DC balanced)
  0xA5 -> 66 99   (popcount 4+4, DC balanced)
  0x5A -> 99 66   (popcount 4+4, DC balanced)
  0x21 -> A6 A9   (popcount 4+4, DC balanced)

  Only 16 byte values can ever appear in coded data.
  0x00 and 0xFF are UNREACHABLE -> use one as the radio sync delimiter.
  (A deliberate code violation, exactly as Ethernet and Token Ring do.)
